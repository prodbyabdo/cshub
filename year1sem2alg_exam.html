Section A — Matrices & Trace
Q01TRACE

Find \(\text{tr}(A)\) where \(A = \begin{pmatrix}5 & 2 & 0 \\ -1 & 3 & 7 \\ 4 & 0 & -2\end{pmatrix}\).

\(\text{tr}(A) = 5 + 3 + (-2) = \boxed{6}\) — sum of main diagonal entries.
Q02TRACE

If \(\text{tr}(A) = 7\) and \(\text{tr}(B) = -3\), find \(\text{tr}(2A - B)\).

\(\text{tr}(2A-B) = 2\,\text{tr}(A) - \text{tr}(B) = 2(7) - (-3) = 14 + 3 = \boxed{17}\).
Q03MATRICES

Which statement about \(\text{tr}(AB)\) is always true for square matrices \(A\) and \(B\)?

\(\text{tr}(AB) = \text{tr}(BA)\) always, even when \(AB \neq BA\). This is a standard trace property.
Q04MATRICES

Compute \(AB\) where \(A = \begin{pmatrix}1 & 2 \\ 3 & 4\end{pmatrix}\) and \(B = \begin{pmatrix}0 & 1 \\ 1 & 0\end{pmatrix}\).

\(AB = \begin{pmatrix}1\cdot0+2\cdot1 & 1\cdot1+2\cdot0 \\ 3\cdot0+4\cdot1 & 3\cdot1+4\cdot0\end{pmatrix} = \begin{pmatrix}2&1\\4&3\end{pmatrix}\).
Q05MATRICES

What is the transpose of \(A = \begin{pmatrix}1 & 4 \\ 2 & 5 \\ 3 & 6\end{pmatrix}\)?

Transpose swaps rows and columns: \(A^T = \begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}\).
Q06TRACE

If \(A\) is a \(3\times3\) matrix and \(\text{tr}(A^T) = 9\), what is \(\text{tr}(A)\)?

\(\text{tr}(A^T) = \text{tr}(A)\) always. So \(\text{tr}(A) = \boxed{9}\).
Q07MATRICES

For matrices \(A\) (\(2\times3\)) and \(B\) (\(3\times4\)), what is the size of \(AB\)?

\(A\) is \(m\times k\) and \(B\) is \(k\times n\) → \(AB\) is \(m\times n = \boxed{2\times4}\).
Q08TRACE

If \(A = \begin{pmatrix}k & 0 \\ 0 & 3\end{pmatrix}\) and \(\text{tr}(A) = 8\), find \(k\).

\(\text{tr}(A) = k + 3 = 8 \implies k = \boxed{5}\).
Section B — Determinants
Q09DETERMINANT

Find \(\det\begin{pmatrix}4 & 7 \\ 2 & 6\end{pmatrix}\).

\(\det = 4\cdot6 - 7\cdot2 = 24 - 14 = \boxed{10}\).
Q10DETERMINANT

Find \(\det\begin{pmatrix}1 & 0 & 2 \\ 3 & 1 & 0 \\ 0 & 4 & -1\end{pmatrix}\).

Expand along row 1: \[ \det(A) = 1\begin{vmatrix}1&0\\4&-1\end{vmatrix} -0 +2\begin{vmatrix}3&1\\0&4\end{vmatrix} \] \[ =1(-1-0)+2(12-0) =-1+24 =\boxed{23} \]
Q11DETERMINANT

If \(\det(A) = 6\) for a \(3\times 3\) matrix, find \(\det(3A)\).

\(\det(kA) = k^n\det(A)\) for \(n\times n\). Here \(n=3\), so \(\det(3A) = 3^3\cdot 6 = 27\cdot 6 = \boxed{162}\).
Q12DETERMINANT

If swapping two rows of \(A\) gives matrix \(B\) with \(\det(B) = 5\), find \(\det(A)\).

Swapping two rows multiplies the determinant by \(-1\). So \(\det(A) = -\det(B) = \boxed{-5}\).
Q13DETERMINANT

When is a matrix \(A\) invertible?

A matrix is invertible (non-singular) if and only if \(\det(A) \neq 0\).
Q14DETERMINANT

Given \(\det(A)=4\) and \(\det(B)=3\), find \(\det(AB)\).

\(\det(AB) = \det(A)\cdot\det(B) = 4\cdot3 = \boxed{12}\).
Q15DETERMINANT

Find \(\det\begin{pmatrix}2 & -1 \\ 4 & 3\end{pmatrix}\).

\(\det = 2\cdot3 - (-1)\cdot4 = 6+4 = \boxed{10}\).
Q16DETERMINANT

If matrix \(A\) has a row of all zeros, then \(\det(A)\) equals:

Any matrix with an all-zero row (or column) has \(\det(A) = \boxed{0}\) and is therefore singular (non-invertible).
Q17DETERMINANT

The cofactor \(C_{12}\) of \(A = \begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}\) equals:

\(C_{12} = (-1)^{1+2}M_{12}\). \(M_{12} = \det\begin{pmatrix}4&6\\7&9\end{pmatrix} = 36-42=-6\). So \(C_{12}=(-1)^3\cdot(-6)=\boxed{6}\).
Q18DETERMINANT

If \(\det(A) = 5\), find \(\det(A^T)\).

\(\det(A^T) = \det(A) = \boxed{5}\) always.
Section C — Cramer's Rule
Q19CRAMER

Use Cramer's Rule to solve \(\begin{cases}x + y = 4 \\ 2x - y = 2\end{cases}\). Find \(x\).

\(\det(A)=\det\begin{pmatrix}1&1\\2&-1\end{pmatrix}=-3\). \(\det(A_1)=\det\begin{pmatrix}4&1\\2&-1\end{pmatrix}=-6\). \(x=\frac{-6}{-3}=\boxed{2}\).
Q20CRAMER

For the system in Q19, find \(y\).

\(\det(A_2)=\det\begin{pmatrix}1&4\\2&2\end{pmatrix}=2-8=-6\). \(y=\frac{-6}{-3}=\boxed{2}\). Check: \(x+y=4\) ✓.
Q21CRAMER

In Cramer's Rule, \(A_i\) is formed by replacing which part of \(A\)?

Column \(i\) of \(A\) is replaced by the vector \(\mathbf{b}\). This is the definition of \(A_i\) in Cramer's Rule.
Q22CRAMER

Cramer's Rule can be applied when:

Cramer's Rule requires \(\det(A)\neq 0\), i.e., the system has exactly one unique solution.
Q23CRAMER

Solve \(\begin{cases}3x + y = 7 \\ x - y = 1\end{cases}\) using Cramer's Rule. Find \(x\).

\(\det(A)=\det\begin{pmatrix}3&1\\1&-1\end{pmatrix}=-4\). \(\det(A_1)=\det\begin{pmatrix}7&1\\1&-1\end{pmatrix}=-8\). \(x=\frac{-8}{-4}=\boxed{2}\).
Q24CRAMER

For the system in Q23, find \(y\).

\(\det(A_2)=\det\begin{pmatrix}3&7\\1&1\end{pmatrix}=3-7=-4\). \(y=\frac{-4}{-4}=\boxed{1}\). Check: \(2-1=1\) ✓.
Q25CRAMER

The formula for Cramer's Rule is \(x_i = \):

\(x_i = \dfrac{\det(A_i)}{\det(A)}\) where \(A_i\) has column \(i\) replaced by \(\mathbf{b}\).
Section D — Matrix Inverse
Q26INVERSE

Find \(A^{-1}\) for \(A = \begin{pmatrix}1 & 2 \\ 3 & 4\end{pmatrix}\).

\(\det(A)=4-6=-2\). \(A^{-1}=\frac{1}{-2}\begin{pmatrix}4&-2\\-3&1\end{pmatrix} = \begin{pmatrix}-2&1\\\frac{3}{2}&-\frac{1}{2}\end{pmatrix}\). The answer matching this form is option B: \(-\frac{1}{2}\begin{pmatrix}4&-2\\-3&1\end{pmatrix}\).
Q27INVERSE

Which of the following is true about \((AB)^{-1}\)?

\((AB)^{-1} = B^{-1}A^{-1}\). The order reverses — this is a key property students often get wrong.
Q28INVERSE

If \(\det(A) = 8\), find \(\det(A^{-1})\).

\(\det(A^{-1}) = \frac{1}{\det(A)} = \frac{1}{8}\).
Q29INVERSE

The adjugate (adj) of a matrix is:

The adjugate (classical adjoint) is the transpose of the cofactor matrix. Then \(A^{-1} = \frac{1}{\det(A)}\text{adj}(A)\).
Q30INVERSE

Which matrix has no inverse?

Check determinants: B: \(2\cdot2-4\cdot1=0\). A matrix with \(\det=0\) has no inverse. Answer: \(\begin{pmatrix}2&4\\1&2\end{pmatrix}\).
Q31INVERSE

\((A^{-1})^{-1}\) equals:

\((A^{-1})^{-1} = A\). Taking the inverse twice returns the original matrix.
Q32INVERSE

The 2×2 inverse formula \(A^{-1} = \frac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\) applies to:

The formula applies to any \(2\times2\) matrix \(A = \begin{pmatrix}a&b\\c&d\end{pmatrix}\) as long as \(\det(A) = ad-bc \neq 0\).
Section E — Linear Transformations
Q33LINEAR TRANS

Which two properties must \(T\) satisfy to be a linear transformation?

A linear transformation must satisfy: (1) Additivity: \(T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})\), and (2) Homogeneity: \(T(c\mathbf{u})=cT(\mathbf{u})\).
Q34LINEAR TRANS

Which of the following is NOT a linear transformation?

\(T(x,y)=(x+1,y)\): check \(T(\mathbf{0})=(1,0)\neq(0,0)\). Since every linear map must send \(\mathbf{0}\) to \(\mathbf{0}\), this is NOT linear. The zero map D is trivially linear.
Q35LINEAR TRANS

For any linear transformation \(T\), what is \(T(\mathbf{0})\)?

Since every linear transformation satisfies \(T(\mathbf{0}) = \mathbf{0}\), finding \(T(\mathbf{0})\neq\mathbf{0}\) is sufficient to conclude a map is not linear — but the converse alone doesn't prove linearity.
Q36LINEAR TRANS

The kernel (null space) of \(T\) is the set of vectors \(\mathbf{v}\) such that:

\(\ker(T) = \{\mathbf{v} \in V \mid T(\mathbf{v}) = \mathbf{0}\}\). The kernel is always a subspace.
Q37LINEAR TRANS

The Rank-Nullity theorem states \(\dim(\ker T) + \dim(\text{Im}\,T)\) equals:

\(\dim(\ker T) + \dim(\text{Im}\,T) = \dim(V)\) where \(V\) is the domain of \(T\).
Q38LINEAR TRANS

Is \(T(x,y) = (x^2, y)\) a linear transformation?

Test homogeneity: \(T(cx,cy) = (c^2x^2, cy)\) but \(cT(x,y) = (cx^2, cy)\). Since \(c^2x^2 \neq cx^2\) in general, homogeneity fails. NOT linear.
Q39LINEAR TRANS

Which is the correct combined linearity test?

The combined single-test form is \(T(c\mathbf{u}+d\mathbf{v}) = cT(\mathbf{u})+dT(\mathbf{v})\). This simultaneously checks both additivity and homogeneity.
Section F — Vectors & Unit Vectors
Q40VECTORS

Find the magnitude of \(\mathbf{v} = (3, -4, 0)\).

\(\|\mathbf{v}\| = \sqrt{9+16+0} = \sqrt{25} = \boxed{5}\).
Q41VECTORS

Find the unit vector in the direction of \(\mathbf{a} = (0, 5, 0)\).

\(\|\mathbf{a}\|=5\). Unit vector \(=\frac{\mathbf{a}}{5}=(0,1,0)\).
Q42VECTORS

Given \(\mathbf{u}=(1,2,3)\) and \(\mathbf{v}=(4,0,-1)\), compute \(\mathbf{u}\cdot\mathbf{v}\).

\(\mathbf{u}\cdot\mathbf{v} = 1\cdot4 + 2\cdot0 + 3\cdot(-1) = 4+0-3 = \boxed{1}\).
Q43VECTORS

Vectors \(\mathbf{u}\) and \(\mathbf{v}\) are orthogonal (perpendicular) when:

\(\mathbf{u}\perp\mathbf{v} \iff \mathbf{u}\cdot\mathbf{v} = 0\). The dot product (inner product) being zero is the definition of orthogonality.
Q44VECTORS

Given \(\mathbf{u}=(2,-1,3)\) and \(\mathbf{v}=(1,4,-2)\), find \(\mathbf{u}-\mathbf{v}\).

\(\mathbf{u}-\mathbf{v} = (2-1,\,-1-4,\,3-(-2)) = \boxed{(1,-5,5)}\).
Section G — Inner Product Space
Q45INNER PRODUCT

The Cauchy–Schwarz inequality states:

\(|\langle\mathbf{u},\mathbf{v}\rangle| \leq \|\mathbf{u}\|\|\mathbf{v}\|\). Equality holds iff \(\mathbf{u}\) and \(\mathbf{v}\) are parallel.
Q46INNER PRODUCT

The norm induced by an inner product is \(\|\mathbf{u}\| = \):

\(\|\mathbf{u}\| = \sqrt{\langle\mathbf{u},\mathbf{u}\rangle}\). The positive-definite axiom ensures \(\langle\mathbf{u},\mathbf{u}\rangle\geq0\), so the square root is real.
Q47INNER PRODUCT

An orthonormal set satisfies \(\langle\mathbf{e}_i,\mathbf{e}_j\rangle = \):

\(\langle\mathbf{e}_i,\mathbf{e}_j\rangle = \delta_{ij}\) (Kronecker delta): equals 1 when \(i=j\) (unit length) and 0 when \(i\neq j\) (orthogonal).
Section H — Straight Line Equations
Q48LINES

Find the distance from point \((2, 3)\) to the line \(3x + 4y - 5 = 0\).

\(d = \frac{|3(2)+4(3)-5|}{\sqrt{9+16}} = \frac{|6+12-5|}{5} = \frac{13}{5} = \boxed{2.6}\).
Q49LINES

A line passes through \((1,2,3)\) with direction \(\mathbf{d}=(2,-1,4)\). Write the parametric equations.

Parametric form: \(x=x_0+at, y=y_0+bt, z=z_0+ct\). With \(P_0=(1,2,3)\) and \(\mathbf{d}=(2,-1,4)\): \(\boxed{x=1+2t,\;y=2-t,\;z=3+4t}\).
Q50LINES

The slope of the line \(2x - 3y + 6 = 0\) is:

Rewrite: \(3y = 2x+6 \implies y = \frac{2}{3}x + 2\). Slope \(= \boxed{\frac{2}{3}}\).
