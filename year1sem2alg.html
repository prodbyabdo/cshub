1. Matrices & Trace EXAM

Matrix Basics

An \(m \times n\) matrix has \(m\) rows and \(n\) columns. Entry at row \(i\), column \(j\) is written \(a_{ij}\).

Trace of a Matrix

The trace of a square matrix is the sum of its main diagonal entries:

\[\text{tr}(A) = a_{11} + a_{22} + \cdots + a_{nn} = \sum_{i=1}^{n} a_{ii}\]

Trace Properties

  • \(\text{tr}(A + B) = \text{tr}(A) + \text{tr}(B)\)
  • \(\text{tr}(cA) = c\,\text{tr}(A)\)
  • \(\text{tr}(AB) = \text{tr}(BA)\)  (even when \(AB \neq BA\))
  • \(\text{tr}(A^T) = \text{tr}(A)\)
EXAMPLE — TRACE

Given \(A = \begin{pmatrix}3 & 1 & 0 \\ 2 & -5 & 4 \\ 1 & 0 & 7\end{pmatrix}\), find \(\text{tr}(A)\).

\(\text{tr}(A) = 3 + (-5) + 7 = \boxed{5}\)

Matrix Operations

OperationRule
Addition \(A + B\)Add corresponding entries. Requires same size.
Scalar multiply \(cA\)Multiply every entry by \(c\).
Multiply \(AB\)\((AB)_{ij} = \sum_k a_{ik}b_{kj}\). Cols of \(A\) = Rows of \(B\).
Transpose \(A^T\)Reflect across main diagonal: \((A^T)_{ij} = a_{ji}\).

2. Determinant (المحدد) EXAM

2×2 Determinant

\[\det\begin{pmatrix}a & b \\ c & d\end{pmatrix} = ad - bc\]

3×3 Determinant — Cofactor Expansion (along Row 1)

\[\det(A) = a_{11}C_{11} + a_{12}C_{12} + a_{13}C_{13}\]

where cofactor \(C_{ij} = (-1)^{i+j} M_{ij}\) and \(M_{ij}\) is the minor (determinant of the matrix with row \(i\) and column \(j\) removed).

Sign pattern for cofactors: \[\begin{pmatrix}+ & - & + \\ - & + & - \\ + & - & +\end{pmatrix}\]
EXAMPLE — 3×3 DETERMINANT

Find \(\det\begin{pmatrix}2 & 1 & 3 \\ 0 & -1 & 4 \\ 5 & 2 & 1\end{pmatrix}\)

Expand along row 1:

\[\det = 2\det\begin{pmatrix}-1&4\\2&1\end{pmatrix} - 1\det\begin{pmatrix}0&4\\5&1\end{pmatrix} + 3\det\begin{pmatrix}0&-1\\5&2\end{pmatrix}\] \[= 2(-1-8) - 1(0-20) + 3(0-(-5))\] \[= 2(-9) - 1(-20) + 3(5) = -18 + 20 + 15 = \boxed{17}\]

Key Determinant Properties

  • If a row/column is all zeros → \(\det = 0\)
  • Swapping two rows multiplies \(\det\) by \(-1\)
  • Multiplying a row by \(k\) multiplies \(\det\) by \(k\)
  • Adding a multiple of one row to another: \(\det\) unchanged
  • \(\det(AB) = \det(A)\cdot\det(B)\)
  • \(\det(A^T) = \det(A)\)
  • \(\det(kA) = k^n \det(A)\) for an \(n\times n\) matrix
  • Matrix is invertible \(\iff \det(A) \neq 0\)

3. Cramer's Rule (قاعدة كرامر) EXAM

Solves a linear system \(A\mathbf{x} = \mathbf{b}\) where \(\det(A) \neq 0\).

For each variable \(x_i\):

\[x_i = \frac{\det(A_i)}{\det(A)}\]

where \(A_i\) is the matrix \(A\) with column \(i\) replaced by \(\mathbf{b}\).

EXAMPLE — 2×2 CRAMER'S RULE

Solve: \(\begin{cases}2x + y = 5\\3x - 2y = 4\end{cases}\)

Step 1. \(\det(A) = \det\begin{pmatrix}2&1\\3&-2\end{pmatrix} = -4-3 = -7\)

Step 2. Replace column 1 with \(\mathbf{b}\): \[\det(A_1) = \det\begin{pmatrix}5&1\\4&-2\end{pmatrix} = -10-4 = -14 \implies x = \frac{-14}{-7} = 2\]

Step 3. Replace column 2 with \(\mathbf{b}\): \[\det(A_2) = \det\begin{pmatrix}2&5\\3&4\end{pmatrix} = 8-15 = -7 \implies y = \frac{-7}{-7} = 1\]

Solution: \(\boxed{x=2,\; y=1}\)

EXAMPLE — 3×3 CRAMER'S RULE

Solve: \(\begin{cases}x + y + z = 6\\ 2x - y + z = 3\\ x + 2y - z = 2\end{cases}\)

\[A = \begin{pmatrix}1&1&1\\2&-1&1\\1&2&-1\end{pmatrix},\quad \mathbf{b}=\begin{pmatrix}6\\3\\2\end{pmatrix}\]

\(\det(A) = 1(1-2) - 1(-2-1) + 1(4+1) = -1+3+5 = 7\)

\(x = \frac{\det(A_1)}{7},\quad y = \frac{\det(A_2)}{7},\quad z = \frac{\det(A_3)}{7}\) — substitute \(\mathbf{b}\) into each column in turn.

⚠ When NOT to use Cramer's Rule: If \(\det(A) = 0\) the system has no unique solution — it is either inconsistent (no solution) or dependent (infinitely many).

4. Inverse of a Matrix EXAM

The inverse \(A^{-1}\) exists only when \(\det(A) \neq 0\). It satisfies \(AA^{-1} = A^{-1}A = I\).

2×2 Inverse Formula

\[A = \begin{pmatrix}a&b\\c&d\end{pmatrix} \implies A^{-1} = \frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\]

Swap the diagonal, negate the off-diagonal, divide by \(\det(A)\).

n×n Inverse via Adjugate

\[A^{-1} = \frac{1}{\det(A)}\,\text{adj}(A)\]

where \(\text{adj}(A)\) is the transpose of the cofactor matrix.

Inverse via Row Reduction [Augmented Method]

Form the augmented matrix \([A \mid I]\) and row-reduce the left side to \(I\). The right side becomes \(A^{-1}\).

\[[A \mid I] \xrightarrow{\text{row ops}} [I \mid A^{-1}]\]
EXAMPLE — 2×2 INVERSE

Find the inverse of \(A = \begin{pmatrix}3 & 1 \\ 5 & 2\end{pmatrix}\)

\(\det(A) = 6-5 = 1\)

\[A^{-1} = \frac{1}{1}\begin{pmatrix}2 & -1 \\ -5 & 3\end{pmatrix} = \begin{pmatrix}2 & -1 \\ -5 & 3\end{pmatrix}\]

Verify: \(A \cdot A^{-1} = \begin{pmatrix}1&0\\0&1\end{pmatrix}\) ✓

Inverse Properties

  • \((A^{-1})^{-1} = A\)
  • \((AB)^{-1} = B^{-1}A^{-1}\) — order reverses!
  • \((A^T)^{-1} = (A^{-1})^T\)
  • \(\det(A^{-1}) = \dfrac{1}{\det(A)}\)

5. Linear Transformations EXAM

A function \(T: V \to W\) is a linear transformation if it satisfies two axioms for all vectors \(\mathbf{u}, \mathbf{v}\) and scalar \(c\):

Axiom 1 — Additivity:

\[T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})\]

Axiom 2 — Homogeneity:

\[T(c\mathbf{u}) = c\,T(\mathbf{u})\]
Quick combined test: \(T\) is linear \(\iff T(c\mathbf{u} + d\mathbf{v}) = cT(\mathbf{u}) + dT(\mathbf{v})\) for all \(c,d,\mathbf{u},\mathbf{v}\).

How to Show T is a Linear Transformation (Exam Method)

  1. Let \(\mathbf{u}, \mathbf{v}\) be arbitrary vectors and \(c\) be an arbitrary scalar.
  2. Compute \(T(\mathbf{u} + \mathbf{v})\) and check it equals \(T(\mathbf{u}) + T(\mathbf{v})\).
  3. Compute \(T(c\mathbf{u})\) and check it equals \(c\,T(\mathbf{u})\).
  4. Conclude: "Since both properties hold, \(T\) is a linear transformation." ✓
EXAMPLE — SHOW T IS LINEAR

Let \(T:\mathbb{R}^2 \to \mathbb{R}^2\) be defined by \(T(x,y) = (2x+y,\ x-3y)\). Show \(T\) is linear.

Let \(\mathbf{u}=(x_1,y_1)\), \(\mathbf{v}=(x_2,y_2)\), \(c\in\mathbb{R}\).

Additivity:

\[T(\mathbf{u}+\mathbf{v}) = T(x_1+x_2,\, y_1+y_2) = (2(x_1+x_2)+(y_1+y_2),\; (x_1+x_2)-3(y_1+y_2))\] \[= (2x_1+y_1,\; x_1-3y_1) + (2x_2+y_2,\; x_2-3y_2) = T(\mathbf{u})+T(\mathbf{v}) \checkmark\]

Homogeneity:

\[T(c\mathbf{u}) = T(cx_1,cy_1) = (2cx_1+cy_1,\; cx_1-3cy_1) = c(2x_1+y_1,\; x_1-3y_1) = cT(\mathbf{u}) \checkmark\]

∴ \(T\) is a linear transformation.

EXAMPLE — SHOW T IS NOT LINEAR

Let \(T(x,y) = (x+1, y)\). Is it linear?

Test \(T(\mathbf{0}) = T(0,0) = (1, 0) \neq (0,0)\).

A linear map must always satisfy \(T(\mathbf{0}) = \mathbf{0}\). Since it doesn't, \(T\) is NOT linear.

Kernel and Image

Kernel (Null Space): \(\ker(T) = \{\mathbf{v} \in V \mid T(\mathbf{v}) = \mathbf{0}\}\)

Image (Range): \(\text{Im}(T) = \{T(\mathbf{v}) \mid \mathbf{v} \in V\}\)

Rank–Nullity Theorem: \(\dim(\ker T) + \dim(\text{Im}\, T) = \dim(V)\)

6. Vectors EXAM

Basic Operations

For \(\mathbf{u} = (u_1, u_2, u_3)\) and \(\mathbf{v} = (v_1, v_2, v_3)\):

\[\mathbf{u} + \mathbf{v} = (u_1+v_1,\; u_2+v_2,\; u_3+v_3)\] \[\mathbf{u} - \mathbf{v} = (u_1-v_1,\; u_2-v_2,\; u_3-v_3)\] \[c\mathbf{u} = (cu_1,\; cu_2,\; cu_3)\]

Magnitude (Norm)

\[\|\mathbf{u}\| = \sqrt{u_1^2 + u_2^2 + u_3^2}\]

Unit Vector

The unit vector in the direction of \(\mathbf{a}\) is:

\[\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|}\]

\(\|\hat{\mathbf{a}}\| = 1\) always.

EXAMPLE — UNIT VECTOR

Find the unit vector in the direction of \(\mathbf{a} = (3, -4, 0)\).

\(\|\mathbf{a}\| = \sqrt{9+16+0} = 5\)

\[\hat{\mathbf{a}} = \frac{1}{5}(3,-4,0) = \left(\tfrac{3}{5},\; -\tfrac{4}{5},\; 0\right)\]

Dot Product (Scalar Product)

\[\mathbf{u}\cdot\mathbf{v} = u_1v_1 + u_2v_2 + u_3v_3 = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta\]

Vectors are perpendicular (orthogonal) when \(\mathbf{u}\cdot\mathbf{v} = 0\).

Cross Product

\[\mathbf{u}\times\mathbf{v} = \det\begin{pmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\u_1&u_2&u_3\\v_1&v_2&v_3\end{pmatrix}\]

Result is a vector perpendicular to both \(\mathbf{u}\) and \(\mathbf{v}\). \(\|\mathbf{u}\times\mathbf{v}\| = \|\mathbf{u}\|\|\mathbf{v}\|\sin\theta\).

7. Inner Product Space EXAM

An inner product \(\langle \mathbf{u}, \mathbf{v} \rangle\) on a vector space \(V\) satisfies:

  1. Symmetry: \(\langle \mathbf{u},\mathbf{v}\rangle = \langle \mathbf{v},\mathbf{u}\rangle\)
  2. Linearity in first argument: \(\langle \mathbf{u}+\mathbf{w}, \mathbf{v}\rangle = \langle \mathbf{u},\mathbf{v}\rangle + \langle \mathbf{w},\mathbf{v}\rangle\)
  3. Scalar: \(\langle c\mathbf{u},\mathbf{v}\rangle = c\langle \mathbf{u},\mathbf{v}\rangle\)
  4. Positive definite: \(\langle \mathbf{u},\mathbf{u}\rangle \geq 0\), with \(\langle \mathbf{u},\mathbf{u}\rangle = 0 \iff \mathbf{u}=\mathbf{0}\)

Induced Norm & Distance

\[\|\mathbf{u}\| = \sqrt{\langle \mathbf{u},\mathbf{u}\rangle}, \qquad d(\mathbf{u},\mathbf{v}) = \|\mathbf{u}-\mathbf{v}\|\]

Standard inner product on \(\mathbb{R}^n\)

\[\langle \mathbf{u},\mathbf{v}\rangle = \mathbf{u}\cdot\mathbf{v} = \sum_{i=1}^n u_i v_i\]

Cauchy–Schwarz Inequality

\[|\langle \mathbf{u},\mathbf{v}\rangle| \leq \|\mathbf{u}\|\,\|\mathbf{v}\|\]

Orthogonality

\(\mathbf{u} \perp \mathbf{v}\) iff \(\langle \mathbf{u},\mathbf{v}\rangle = 0\).

An orthonormal set has \(\langle \mathbf{e}_i, \mathbf{e}_j\rangle = \delta_{ij}\) (1 if \(i=j\), else 0).

EXAMPLE — INNER PRODUCT

Let \(\mathbf{u}=(1,2,-1)\), \(\mathbf{v}=(3,0,2)\). Find \(\langle\mathbf{u},\mathbf{v}\rangle\), \(\|\mathbf{u}\|\), and the angle \(\theta\).

\[\langle\mathbf{u},\mathbf{v}\rangle = (1)(3)+(2)(0)+(-1)(2) = 3+0-2 = 1\] \[\|\mathbf{u}\| = \sqrt{1+4+1}=\sqrt{6},\quad \|\mathbf{v}\|=\sqrt{9+0+4}=\sqrt{13}\] \[\cos\theta = \frac{1}{\sqrt{6}\cdot\sqrt{13}} = \frac{1}{\sqrt{78}}\implies \theta = \cos^{-1}\!\left(\frac{1}{\sqrt{78}}\right)\]

8. Straight Line Equations EXAM

Line in \(\mathbb{R}^2\)

FormEquationNotes
Slope-intercept\(y = mx + b\)\(m\) = slope, \(b\) = y-intercept
Point-slope\(y - y_1 = m(x - x_1)\)Through point \((x_1,y_1)\)
Standard / General\(ax + by + c = 0\)\(m = -a/b\)
Two-intercept\(\dfrac{x}{a}+\dfrac{y}{b}=1\)x-int = \(a\), y-int = \(b\)

Line in \(\mathbb{R}^3\) — Parametric & Symmetric

Line through point \(P_0=(x_0,y_0,z_0)\) with direction vector \(\mathbf{d}=(a,b,c)\):

Parametric:

\[x = x_0 + at,\quad y = y_0 + bt,\quad z = z_0 + ct,\qquad t\in\mathbb{R}\]

Symmetric:

\[\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}\]

Distance Formulas

Point to line in \(\mathbb{R}^2\) — line \(ax+by+c=0\), point \((x_1,y_1)\):

\[d = \frac{|ax_1+by_1+c|}{\sqrt{a^2+b^2}}\]

Between two parallel lines \(ax+by+c_1=0\) and \(ax+by+c_2=0\):

\[d = \frac{|c_1-c_2|}{\sqrt{a^2+b^2}}\]
EXAMPLE — LINE THROUGH TWO POINTS

Find the line through \(A=(1,2,3)\) and \(B=(4,-1,2)\).

Direction \(\mathbf{d} = B - A = (3,-3,-1)\).

\[\text{Parametric: } x=1+3t,\quad y=2-3t,\quad z=3-t\] \[\text{Symmetric: } \frac{x-1}{3} = \frac{y-2}{-3} = \frac{z-3}{-1}\]

9. Exam Practice Questions PRACTICE

QUESTION 1 — DETERMINANT

Compute \(\det(A)\) where \(A = \begin{pmatrix}1&2&0\\-1&1&3\\2&0&4\end{pmatrix}\).

Expand along row 1:

\[\det = 1\det\begin{pmatrix}1&3\\0&4\end{pmatrix} - 2\det\begin{pmatrix}-1&3\\2&4\end{pmatrix} + 0\] \[= 1(4-0) - 2(-4-6) = 4 - 2(-10) = 4 + 20 = \boxed{24}\]
QUESTION 2 — CRAMER'S RULE

Use Cramer's Rule to solve: \(\begin{cases}x+2y=7\\3x-y=7\end{cases}\)

\[\det(A)=\det\begin{pmatrix}1&2\\3&-1\end{pmatrix}=-1-6=-7\] \[x = \frac{\det\begin{pmatrix}7&2\\7&-1\end{pmatrix}}{-7} = \frac{-7-14}{-7}=\frac{-21}{-7}=3\] \[y = \frac{\det\begin{pmatrix}1&7\\3&7\end{pmatrix}}{-7} = \frac{7-21}{-7}=\frac{-14}{-7}=2\]

\(\boxed{x=3,\; y=2}\)

QUESTION 3 — MATRIX INVERSE

Find \(A^{-1}\) for \(A = \begin{pmatrix}2 & 5 \\ 1 & 3\end{pmatrix}\).

\(\det(A) = 6-5 = 1\)

\[A^{-1} = \frac{1}{1}\begin{pmatrix}3&-5\\-1&2\end{pmatrix} = \begin{pmatrix}3&-5\\-1&2\end{pmatrix}\]
QUESTION 4 — LINEAR TRANSFORMATION

Show that \(T:\mathbb{R}^2\to\mathbb{R}^2\) defined by \(T(x,y)=(3x-y,\; 2x+4y)\) is a linear transformation.

Let \(\mathbf{u}=(x_1,y_1)\), \(\mathbf{v}=(x_2,y_2)\), \(c\in\mathbb{R}\).

Additivity:

\[T(\mathbf{u}+\mathbf{v})=(3(x_1+x_2)-(y_1+y_2),\;2(x_1+x_2)+4(y_1+y_2))\] \[=(3x_1-y_1,2x_1+4y_1)+(3x_2-y_2,2x_2+4y_2)=T(\mathbf{u})+T(\mathbf{v})\;\checkmark\]

Homogeneity:

\[T(c\mathbf{u})=(3cx_1-cy_1,\;2cx_1+4cy_1)=c(3x_1-y_1,\;2x_1+4y_1)=cT(\mathbf{u})\;\checkmark\]

∴ \(T\) is a linear transformation.

QUESTION 5 — VECTORS

Given \(\mathbf{u}=(2,1,-2)\) and \(\mathbf{v}=(1,3,0)\), find: (a) \(\mathbf{u}+\mathbf{v}\), (b) \(\mathbf{v}-\mathbf{u}\), (c) \(\|\mathbf{u}\|\), (d) unit vector in direction of \(\mathbf{u}\).

(a) \(\mathbf{u}+\mathbf{v}=(3,4,-2)\)

(b) \(\mathbf{v}-\mathbf{u}=(-1,2,2)\)

(c) \(\|\mathbf{u}\|=\sqrt{4+1+4}=\sqrt{9}=3\)

(d) \(\hat{\mathbf{u}}=\frac{1}{3}(2,1,-2)=\left(\tfrac{2}{3},\tfrac{1}{3},-\tfrac{2}{3}\right)\)

QUESTION 6 — TRACE

If \(A = \begin{pmatrix}4&1\\2&-3\end{pmatrix}\) and \(B=\begin{pmatrix}1&0\\0&5\end{pmatrix}\), find \(\text{tr}(A+B)\) and \(\text{tr}(AB)\).

\(\text{tr}(A+B)=\text{tr}(A)+\text{tr}(B)=(4-3)+(1+5)=1+6=\boxed{7}\)

\(AB=\begin{pmatrix}4&5\\2&-15\end{pmatrix}\implies\text{tr}(AB)=4+(-15)=\boxed{-11}\)
